# Executive Evasiveness Classifier

This project provides a web interface for classifying whether an executive response directly answers, partially evades, or fully evades an analyst's question. It uses a fine-tuned RoBERTa model behind a FastAPI service, with an Angular frontend for exploring predictions and the project's methodology. More information about research, methodology, data, and results can be found in the About page in the link below!

Try it out here: [executive-classifier.vercel.app](executive-classifier.vercel.app)
