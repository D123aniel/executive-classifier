01

Research question

Can a specialist model detect executive evasiveness?

Earnings calls are a critical communication channel between public companies and investors. When an executive avoids part of an analyst's question, the response can increase information asymmetry and obscure decision-relevant signals.

The project compares 2 approaches on the same locked evaluation set: zero-shot classification with 6 general-purpose language models and a fine-tuned RoBERTa-large classifier trained for this specific task.

Core question

Can a scalable classifier identify whether a response is direct, partially evasive, or fully evasive while improving accuracy, speed, cost, and reproducibility?

02

Labeling framework

Directness is measured against the question

Each example contains an analyst question and an executive response. The label describes how completely the response addresses the question, not whether the language sounds confident, polite, or detailed.

Direct

Clearly answers all key parts of the question with relevant and specific information.

Partially evasive

Addresses the topic but leaves a key component unanswered, vague, or deferred.

Fully evasive

Does not answer the question and instead shifts to unrelated content or a non-answer.

Codebook rule

If all components are answered, label the response Direct. If only some are answered, label it Partially Evasive. If the response does not address the question, label it Fully Evasive.

03

Methodology

From public transcripts to a locked benchmark

  1. 1

    Prepare the data

    The source dataset was EvasionBench, a public benchmark of 16,726 earnings-call question and response pairs. Duplicate questions were consolidated by retaining the longest response.

  2. 2

    Create an independent holdout

    A stratified set of 1,000 pairs was locked before training. At least 3 annotators reviewed each pair using the project codebook, and the final adjudicated labels became the evaluation reference.

  3. 3

    Benchmark general-purpose models

    6 language models from Google, OpenAI, and Anthropic classified the same holdout using a fixed codebook-based prompt. Gemini 3 Flash produced the strongest general-purpose baseline.

  4. 4

    Fine-tune the specialist model

    RoBERTa-large was trained as a 3-class sequence classifier on 12,505 training pairs and selected using macro F1 on a 3,127-pair validation set. The question and response are encoded together with a 512-token limit.

04

Evaluation

The specialist model led on every primary metric

On the 1,000-pair human-labeled holdout, the fine-tuned model reached 88.9% accuracy and a 0.835 macro F1. It outperformed Gemini 3 Flash, the strongest of the 6 general-purpose models tested.

What the errors showed

94 of the model's 111 errors occurred between Direct and Partially Evasive. This reflects the most subjective boundary in the codebook. Fully Evasive was also rare, with only 27 examples in the final holdout.

05

Responsible use

A decision-support signal, not a final judgment

Labels require judgment

Borderline responses can reasonably be interpreted differently, especially between Direct and Partially Evasive.

The rare class is small

Fully Evasive represents 27 holdout examples, limiting how precisely its performance can be estimated.

Context is limited

The model evaluates one question and response pair. It does not use the full call, prior exchanges, company history, or market context.

Scores need interpretation

Output scores are relative model scores, not calibrated probabilities. Low-score or low-margin predictions should receive human review.

Appropriate use

This academic tool supports research and exploration. It should not be used as a standalone basis for investment, legal, compliance, or personnel decisions.

The application code does not persist submitted questions or responses. The model scales to zero between periods of use, so the first request after an idle period can take longer while the service starts.

Requests longer than 512 model tokens are truncated and marked in the response. Predictions with a top score below 0.60 or a top-2 margin below 0.15 are flagged for review.
